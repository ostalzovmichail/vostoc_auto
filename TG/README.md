# TG — телеграм-бот для сохранения сообщений на диск

Бот на Rust + [teloxide](https://github.com/teloxide/teloxide). Сохраняет на ПК
то, что ему присылают: **содержимое сообщений — в текстовом формате (`.txt`)**,
**фотографии — в формате `.jpg`**.

## Имя файла

```text
<метка>_<id>[_<номер>].<расширение>
```

* **метка** — первое слово первой строки текста (или подписи к фото);
* **id** — сквозной номер, который бот присваивает при сохранении;
* **номер** — только у альбомов: фото одной группы различаются им.

Примеры: `Привет_7.txt`, `Поездка_12.jpg`, а для альбома — `Поездка_12_1.jpg`,
`Поездка_12_2.jpg`, `Поездка_12_3.jpg`.

Из метки убираются символы, неудобные в имени файла (остаются буквы, цифры,
`-`, `_`). Если подходящего слова нет (например, подписи нет вовсе),
подставляется `photo` для фото и `text` для текста.

## Что сохраняется

| Пришло боту | Что появляется на диске |
|---|---|
| Текст | `data/text/<chat_id>/<метка>_<id>.txt` с текстом сообщения |
| Фото | `data/photos/<chat_id>/<метка>_<id>.jpg` (наибольший размер) |
| Подпись к фото | `data/text/<chat_id>/<метка>_<id>.txt` с тем же id |
| Фото, отправленное «как файл» (JPEG) | тоже `.jpg` |
| **Альбом** (несколько фото одним сообщением) | все фото получают **общий id** и метку из подписи, различаются номером |

Пример раскладки:

```text
data/
  next_id                                          — последний выданный id
  text/123456789/Привет_7.txt
  photos/123456789/Поездка_12_1.jpg
  photos/123456789/Поездка_12_2.jpg
  text/123456789/Поездка_12.txt                    — подпись альбома
```

Стикеры, голосовые, видео и прочие типы не сохраняются.

## Настройка

```bash
cp .env.example .env
# откройте .env и вставьте токен от @BotFather
```

Переменные:

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `TELOXIDE_TOKEN` | токен бота (обязателен) | — |
| `DATA_DIR` | куда сохранять | `./data` |
| `RUST_LOG` | уровень логов | `info` |

## Запуск

```bash
cargo run            # dev
cargo run --release  # быстрее
```

При старте бот проверяет токен (`get_me`) и печатает своё имя — если токен
неверный, вы сразу увидите ошибку, а не «тишину» в логах. Остановка — `Ctrl+C`.

## Тесты

```bash
cargo test
```

Проверяются правила именования, раскладка каталогов, сохранение текста и
непрерывность счётчика id — без обращения к Telegram (сеть не нужна).

## Структура

```text
TG/
  Cargo.toml
  .env.example      — шаблон конфигурации
  src/
    main.rs         — запуск, диспетчер и обработчики сообщений
    config.rs       — токен и каталог из окружения
    naming.rs       — правила имён файлов (метка + id)
    storage.rs      — запись .txt, скачивание .jpg и счётчик id
    album.rs        — сборка альбомов (несколько фото одним сообщением)
  data/             — создаётся при работе (в .gitignore)
```

## Замечания

- Фотографии Telegram отдаёт уже в JPEG, поэтому скачанное сохраняется с
  расширением `.jpg`.
- Альбом сохраняется после короткой паузы (~1 с) — за это время приходят все
  фото группы, после чего в чат уходит один отчёт.
- Подпись альбома пишется отдельным `.txt` с тем же id, что и фото.
- Счётчик id лежит в `data/next_id` и не сбрасывается при перезапуске.
- Токен лежит в `.env`, который добавлен в `.gitignore` — в репозиторий он не
  попадёт.
